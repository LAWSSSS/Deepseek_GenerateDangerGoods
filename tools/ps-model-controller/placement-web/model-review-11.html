检查重点

观察绿色铸造底座（裙边、五条放射筋和中心凸台）、锥形筒体、12 面绿色上环与镀铬螺杆、深色顶帽、筒体上的 5T 铸字、重绘标签，以及左侧杠杆组件：空心矩形操作杆的开口端、圆形插座、齿轮座圆端面与六角螺栓、下部支架/连杆、亮绿拉钮，还有提环与两处连接座/销。

本件六视图为 visual_match_unverified（未标定外观匹配），且各面板不是一致的转台：参考把杠杆画成圆管，照片清楚显示为空心矩形杆；参考正视把提环画在筒体右侧，照片则显示提环与杠杆同在可见侧，候选以照片为准并把参考该处视为镜像。参考左右视的杠杆近水平，照片约向上 35°，候选取一致的上倾姿态。原模型虽通过单张源图轮廓 IoU 0.955，但六方向审计显示表面糊化、标签不可辨、提环/齿轮座与筒体粘连，故未复用旧网格。新候选严格原视角轮廓 IoU 0.2224 仅作诊断（照片为 3/4 而严格相机为正视），315° 转台按包围盒对齐后的诊断 IoU 0.6858，两者都不是验收通过。隔离渲染确认杠杆矩形通孔 1/1、提环内开口 1/1；49 个部件网格闭合、同部件无自交，PBR 材质瓦片和金属反射变光检查通过。齿轮座内部、拉钮功能/轴、提环背面连接、5T 浮雕、标签原始印刷、底面细节与所有隐藏面均为推断。候选为 manual_only，不替换原模型，不进入自动放置或正式合成；落稳与现场尺度未验证。

# 摄影判断与操作映射

## 现场参照

以完整成图确定光线环境和局部落点，再在原尺寸检查边缘。参照同层、近距离、方向和材质相近的表面。用深浅分位数、色度、边缘扩散和噪声做交叉检查。表面法线、反照率和相机响应未知时，亮度差支持复核线索，无法单独求出入射光、镜头光圈或曝光值。色度统计分开看金属和漆面，白标签、孔洞、遮挡和镜面高光可能使整件均值失真。

| 判断 | 可核对的线索 | 对应处理 |
|---|---|---|
| 接触与投影 | 接触斑附近有暗部，投影方向与邻近物一致。先辨认可见空气缝、相交和反向遮挡 | 接触影和承托面交回几何与接收面检查。虚拟接收面上的接触证据单列 |
| 主光与补光 | 多块同朝向表面和邻近投影显示一致方向，比较受光面与背光面的比例 | 渲染阶段验证方向、光源角尺寸与主补光比例。曝光曲线只能改变明暗 |
| 镜面反光 | 同材质曲面的高光随法线和视角变化。大光源与粗糙表面都可产生宽反射 | 结合镜面通道、材质粗糙度及局部反射场定位。单张高光宽度不足以分离光源和粗糙度 |
| 积灰、锈蚀和磨损 | 尘土在朝上、遮蔽和凹处沉积，凸缘与加工面有磨耗。锈层颜色、粗糙度与细凹凸共同作用 | 已确认材质分区使用物体空间处理，保留标签和原法线。现有自动控制仅提供有效的浮灰覆盖档位 |
| 雾幕 | 相近深度的暗部抬升、对比降低且色偏一致，排除反光、浅色材料和剪裁高光 | 在线性成像中把表面光和空气散射分开，使用现有局部透射率。雾色和雾量分别诊断 |
| 中间调、黑位、高光 | 对照同类漫反射表面亮度分位数；独立核对暗部抬升、高光通道剪裁、明暗跨度 | 选有效的曝光或对比度小步。黑位、高光超出可用控制时保留待审 |
| 冷暖、绿洋红与色度 | 中性漫反射参照的 Lab a*、b* 提供颜色线索。颜色幅度用 C*；本色与照明偏色分开 | 冷暖可用已注册的校正值，色度按材质限制。独立绿洋红校正需要相应控制和中性参照 |
| 锐度、噪声、压缩 | 在最终像素比较同层相似边缘宽度和平坦区域残差。轮廓接缝、划痕纹理、压缩振铃各自定位 | 相机清晰度使用已有单次过滤预算。保持透明度、孔洞和前景原像素。噪声与压缩仍独立评估 |

## 两模型交接

`photo-brief-v1` 的 `direction` 表示摄影量需要增减。例如 `sharpness/decrease` 允许增大相机模糊，`chroma/decrease` 可能对应程序中更大的去色强度。已有 `contrast` 档位也可能反向改变实际对比度。以有效测量值和控制映射确定方向。显示 luma 以 sRGB 加权码值 0–255 报告，EV 属于渲染曝光，Photoshop 曲线中点的码值单位独立。参考不够时记录未知。

执行模型每轮只接收当前关键发现和至多三个绝对值选项。程序校验发现区域、等级、方向、冲突、当前状态以及实际可执行范围。光向、接缝或结构问题没有合适选项时由相应阶段复核。重合成和重渲的依赖由当前执行器处理，更新后评审实际成图。

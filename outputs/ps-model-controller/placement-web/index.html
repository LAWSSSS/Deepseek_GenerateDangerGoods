2. 摆放和视角

待审预览会按局部环境匹配光色和画质，并用网格投影检查接触斑。左键拖动移动，切到“拖动旋转”后左键拖动旋转物体 X/Y。右键或 Shift+左键拖动旋转 Z，Alt+拖动调整观察视角。右上圆点同样可旋转，右下角方块调整大小。物体 X/Y/Z 也可直接输入，独立于观察视角。坐标对应原图像素。

绿色十字随拖动移动；调整视角、物体旋转或大小时保持该点。每个足底是否承托仍需单独检查。

3. 对话确认

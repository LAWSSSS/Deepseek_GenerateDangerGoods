# 32 号黑色液压缸 v46：候选记录与可复用做法

## 候选状态

模型保存在 [`32-black-hydraulic-cylinder-v46.blend`](../../model-assets/candidates/32-black-hydraulic-cylinder/v46/32-black-hydraulic-cylinder-v46.blend)，校验信息见同目录的 `manifest.json`。它是独立候选，**没有替换已发布模型，也没有切换批量默认**。Blender 4.5.3 可重开；模型包含 10 个在用材质和 19 张已打包贴图。文件通过 Git LFS 保存。

v46 从 v45 复制而来，底网格指纹不变：204,061 顶点、182,144 面。此版集中加强已有氧化层的颗粒尺度、表面起伏和露钢反射；没有改造几何轮廓、孔洞、UV 或零件关系。置换来自 Cycles 材质节点，最高约 1.3 mm，是工作尺度估计，不是经实物测量的加工尺寸；要在模型检查视图完整显示置换，需用 Cycles Experimental 和自适应细分。

## 从反馈归纳的外观要求

1. **中筒是视觉重点。** 锈化要覆盖整个中筒可见区域，不留大块无缘由的“秃面”；覆盖范围要连续，颜色、颗粒大小和密度仍应不规则，不能像均匀喷漆或重复贴花。
2. **锈要有凸起颗粒。** 不只加红棕色。要让大小不同的锈粒、结块边缘和细坑在近景及侧光下有可见的高度/法线反应，同时保留锈层粗糙、偏哑的表现。
3. **钢和漆要分开。** 活塞杆、接头和端部保留金属高光；端盖的大面积黑色涂漆继续可辨，可在磨损边缘出现少量露钢。不能为了增加金属感把黑漆整块做成裸钢，也不能让金属像塑料一样没有随视角变化的反射。
4. **标签局部剥落。** 黄色标签保留主体、文字和可识别形状，只在少数磨损处露出底下黑漆；不要整张去掉或把标签全部锈蚀。
5. **杆件和端部不能过于崭新。** 加少量分布不均的油污、灰和磨损，让它们与中筒同处废钢环境；仍保留活塞杆加工面及部件边界。
6. **环境融合要在真实全景里判断。** 以落点附近的灰尘、锈色、受光、薄雾和监控清晰度为参照；不以全图平均值染色，也不以棚拍身份图决定现场色光。做旧不能抹掉物品身份。
7. **报告必须可看全图。** 每次先交原尺寸完整环境图，再附模型全身及中筒、端部近景；同条件对照要固定背景、机位、姿态、尺度、前景和成像参数。

“锈覆盖 50%”曾作为单次试验值，不应当作所有物品的通用常数。对 32 的验收重点是中筒实际视觉覆盖连续且自然，同时钢、黑漆、标签、杆部各自保留材质身份。未来物品应按六视图、实际表面尺寸和最终投影像素重新确定参数，不能复制本版毫米数或材质编号。

## v46 的实际调整和边界

- 在原有氧化遮罩上，将颗粒节点的工作间距设为约 2.78 mm；凹凸距离约 1.0 mm；Cycles 着色器置换最高约 1.3 mm。此版增强的是颗粒读感，不等同于扩大了锈色遮罩覆盖率。
- 露钢材质仍为金属，调整其粗糙/光泽分支并保留约 0.20 的各向异性，使端部和杆件不只靠底色呈现金属感。
- 黑色漆、铸钢和加工钢仍为独立部件材质组。改动节点清单与文件散列写入 `manifest.json`；贴图已打包在 `.blend`，不需要仓库外的本地贴图目录。
- 已将模型放回 53 号监控背景，保持此前场景测试的相机、位置、姿态和尺寸，生成 3840×2160 全景。该预览未调用视觉 API；现场接触证据仍未知，尺度属于估计，因此它只用于外观检查，不是正式物理验收。全景中物品的锈色仍较醒目，需由用户判断是否继续压低与环境的差异。

## 后续逐件建模的推荐顺序

1. 冻结已发布模型、六视图和原始贴图的散列；每次修改另存新版本，不覆盖源资产。
2. 先核对零件身份、材质槽、UV 和视图方向，建立端盖/筒身/焊缝/杆件/标签的部件表及保护区域。
3. 先做灰模和源材质检查。只有多视图或结构证据指出轮廓问题时才改几何；单纯缺少磨损不通过全局细分模型解决。
4. 分开控制涂层、裸钢、氧化和积灰。先让颜色遮罩位置符合六视图，再分别校准粗糙度、法线和置换；不要用均匀厚灰或全表面红锈掩盖贴图错位。
5. 颗粒尺度按物体实物尺寸换算，并检查最终场景分辨率：低于可见像素的细节只影响微表面反射，不应夸大成大凸块。
6. 用同一机位、两种宽面/掠射光和转向图检查：纹理跟随物体、高光跟随灯光，锈、漆、钢和塑料表现不同。
7. 固定几何后做环境合成，优先用全景与局部邻域比较。位置、尺度或阴影变化时重新核验接触；只改材质时不要声称物理摆位得到重新验证。
8. 记录用户要求、改动参数、模型散列、全尺寸图、读回结果、未知项与下一步。候选得到用户确认后再从建模工作台发布。

## 本候选不代表

本轮没有确认 32 的现场实物尺寸、隐藏接触、凹处高度或物理稳定性；没有运行跨背景泛化，也没有将 v46 发布为生产版本。当前需要用户检查中筒锈粒强度、端部金属均匀性以及真实场景里的突兀程度。

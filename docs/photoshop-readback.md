# Photoshop 可测量执行接口

`photoshop-object-export-v2` 继续从注册的原始图层建立临时文档，每次操作都是绝对值。源图、源 PSD 和用户已打开的文档不被覆盖。几何或材质问题不能通过 Photoshop 调色伪装为修复。

## 注册操作与单位

| 操作 | 限幅 | 实际含义 |
| --- | --- | --- |
| brightness | −48 至 48 | RGB 曲线 128 中点的位移；不是曝光 EV |
| black_point | −24 至 24 | 曲线 48 暗部控制点的位移；0/255 端点不变 |
| highlights | −24 至 24 | 曲线 208 亮部控制点的位移；0/255 端点不变 |
| warmth | −24 至 24 | 红、蓝通道曲线的反向位移；不是色温 K |
| tint | −16 至 16 | 绿通道曲线位移；正值偏洋红 |
| saturation | −40 至 40 整数 | Photoshop Hue/Saturation 主饱和度百分点 |

曲线位移使用 8 位编码值单位。Photoshop 会将曲线点量化为整数，因此请求值和实际回读值分别保存；下一轮以实际回读值为准。

清单可附加 `action_masks`（操作名到二值、同画布蒙版路径）及 `action_parts`（操作名到部件 ID）。两者必须完全对应。只有具备主机注册的材质蒙版才能提供该部件的操作；缺失时不能将局部发现变为整件调整。蒙版另受物品 alpha、前景和保护区约束。当前接口每个操作注册一个部件目标，多个相同操作的独立部件值尚未开放。

## 实际状态与测量

固定 JSX 使用 ActionManager/DOM 读取重开 PSD 的文档 ID、图层 ID、曲线点、色相饱和度、不透明度、混合模式、剪贴、蒙版状态、画布和 ICC。文档 ID 是会话局部值，图层 ID 来自保存后的 PSD。原始参数描述与精简的实际生效值均保存，不以请求回显充当回读。

`photoshop-state.json` 绑定最终 PNG 和 PSD 的 SHA-256。后续请求绑定前一轮图片和状态文件散列；过期或被修改的证据拒绝执行。回执保存请求值、量化后的实际值、单位、相对前次参数变化、像素变化与耗时。

`PhotoshopAdapter.inspect()` 只接受主机注册的 PSD 路径和预期散列，复制到临时目录后读取，不打开并关闭用户可能正在编辑的原 PSD。最多接受 12 个归一化矩形区域，返回统计而非大块像素数据：亮度分位数、Lab 色度、线性 sRGB 亮度、局部反差、边缘梯度及平坦区域残差噪声估计。它们不能证明真实粗糙度、照度、相机 PSF 或现场深度。

命令行独立读取：

```powershell
python -m scrap_composite.photoshop_cli --inspect-psd <registered.psd> --sha256 <expected-sha256> --regions <regions.json>
```

区域文件为 `[{"id":"reference","bounds":[0.2,0.3,0.4,0.5]}]`。普通导出接口和历史清单继续可读。

摄影流程预先提供物品和有界邻域统计。邻域排除物品包围范围、孔洞、已知阴影、前景、保护区、极暗与溢出像素；无深度或材质证据时明确标为未知，不能作为同层可靠标尺。

视觉模型还可请求 `ps_layer_state`、`local_pixel_statistics`、`edge_noise_statistics`，有注册部件蒙版时可请求 `material_region_statistics`。每轮最多补充一次只读测量并复诊；结果必须与被评审图片的 RGB 散列一致。未知能力不调用工具、不编造数值，也不启动循环。

## 2026-11-17 实测

本机 Photoshop 26.6 完成六操作导出及 PSD 回读、绑定前次状态后的第二次导出，以及漆面蒙版限定的饱和度导出。蒙版夹具仅改变指定 8,400 像素，透明孔、前景和调整区外像素均通过。只读请求返回两块区域的 6,264 / 5,031 个样本，PSD 原文件未改变；这次读取耗时 5.25 秒。

三次导出记录耗时分别为 46.266、15.828、19.203 秒（含启动/执行/导出，非纯渲染）。另一次早期独立读取没有计时，不并入精确总耗时。未调用模型、未产生 Blender 渲染。本项是桥接和像素守卫验证，不是四件模型的视觉验收。

离线覆盖参数越界、实际回读不符、过期状态、重复绝对值、部件蒙版、测量区域限幅和不可用测量。实际导出保存在忽略目录 `outputs/PS-结构化回读-20261118/`，不提交 PSD/PNG。

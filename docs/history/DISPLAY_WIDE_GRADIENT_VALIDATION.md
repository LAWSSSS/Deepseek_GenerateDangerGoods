## 单变量梯度

| 比较组 | 零档与试验档 | 固定内容 |
|---|---|---|
| 均匀池化 | 原图、16×16、32×32、64×64 | 新光场、材质、基础扬尘、相机成像；追加薄雾为 0 |
| 薄雾 | 无追加、追加 30%、60%、85% | 新光场、材质、基础扬尘、相机成像；池化为 0 |
| 局部取光 | 上轮受光、扩大邻域后的均值受光 | 零池化、零追加雾、摆位与材质 |
| 光场重建 | 扩大邻域后的均值受光、局部近似环境光 | 相同有效样本、零池化、零追加雾、摆位与材质 |

池化在最终物体投影尺寸上进行一次，采用各格内透明度加权算术均值，再双线性恢复尺寸。对不透明样本各像素等权，透明区域的 RGB 不混入表面。三档均以 100% 强度作用于可见物品，不再按细杆、孔沿或轮廓减小池化权重；几何 alpha 保持不变。大格累加使用双精度，防止 64×64 常色区出现数值漂移。

追加薄雾使用实际 30%/60%/85% 混合权重，不再乘以原雾量。各档在线性空间混入当地雾色，保持原几何 alpha；已有基础扬尘与新层合成后的总量上限为 90%。本批最高档实际总遮蔽为 **86.1%–88.7%**。清晰场景原估计为零时不强制加雾。效果重新限定于可见物品，沿用原孔洞、前景及阴影。

带漆金属继续使用上一轮减半后的表面积灰，塑料仍使用非金属材质。31/33 的累计尺寸比例维持 0.375/0.25，没有重复缩小。

## 均值采样与近似光照重建

局部采样边距乘 **1.75**，本批实际邻域面积是原来的 **1.65–1.84 倍**，没有转向全图采样。继续排除文字、前景、过饱和和深暗区域，并以相对深度差 0.085 筛选同层中性表面。对有效像素在解码线性、受限去雾后的工作空间取算术均值，分区也取均值；均值模式不再使用中位数或按亮度分位裁尾。

中性接收面曝光校准同样使用均值，以同一照明下的参考面作为依据，不把每件物品拉到地面亮度。均值方案的校准为 −0.13 至 +0.61 EV，近似光场为 +1.17 至 +1.49 EV，均未触发校准限幅。这些值依赖中性反射率假设，不等于现场实测照度。

新增一个 128×64 浮点环境光场：把局部分区的平均颜色及明暗变化映射为宽而柔和的球面光瓣，通过相机基向量转换方向，再按球面立体角归一化总能量。看不见的上方照明使用明确记录的柔光先验。环境光场承担部分补光后同步减少面积光，避免重复计入光能；每个方案重新生成对应阴影。保存光场数值、散列、样本范围、方向依据和置信度。

这是**由局部外观约束的近似光照重建**。照片中的表面反射率、法线、绝对亮度及画外光源未知，不能称为恢复了真实 HDR 光场。实测 HDR 光照探针可提供更直接的环境辐射依据，参见 [Debevec 的场景合成研究](https://www.pauldebevec.com/Research/IBL/abstract.html)。低频环境表达用于柔和受光的依据见 [Ramamoorthi 与 Hanrahan 的环境辐照研究](https://graphics.stanford.edu/papers/envmap/)；本实现使用宽光瓣，并非复现论文的球谐实现或精度。渲染通过 [Blender 环境纹理](https://docs.blender.org/UATEST/manual/en/4.5/render/lights/world.html)接入。

- 130 项批量检查通过，包括新增的均匀大格池化、透明格归一化、实际雾量、无内侧黑边、算术均值、局部范围隔离、光场能量和真实 Blender 环境方向测试。
- 36 项网页与 8 项模型查看器检查通过。
- 十组独立读取全部 PNG、alpha 与遮挡依据：90 张不同全景，130 个报告图片链接，尺寸和链接均正确。
- 两种新增照明的轮廓 IoU 均为 1，投影与接触锚点偏差为 0；单变量光学组相对零档在可见物品外无像素变化，孔洞、前景、文字保护区通过检查。
- 44 个源模型散列保持一致。
- 完整批次再次执行，十组全部命中合成缓存，2.172 秒结束，无新增渲染及 API。

实际全景抽查表明，64×64 池化及 85% 追加雾会明显削弱孔沿、表面纹理与曲面层次。它们保留为上限试验，不推荐直接作为统一默认。alpha 不变只能证明轮廓和孔洞遮罩没改，不能证明视觉细节仍清晰。尚待用户比较池化强度、雾强度以及两种受光策略。

# 2026-11-11：液压缸缩小、储罐停用与更多物品点评

本轮依据用户新反馈生成 24 张点评图，不是通过既有质量门槛后的扩批。统一摄影策略，无人工选位、蒙版修补或逐图调参。

## 程序修改

- 自动生成默认排除 `5/6/7` 储罐，包括显式模型列表和任务清单。保留源文件与历史记录；复现历史实验可显式设 `excluded_assets=[]`。
- 默认 `asset_scale_factors={"31":0.5}`，对 31 号投影长度和宽度同时减半，保持接触锚点，重算接触簇与接收面，重新核对局部物理。现场尺度仍标记未知，不能以用户指定大小替代尺度证据。
- 新增 `photo_style=dusty_scrap`：结合 `appearance=local`，从落点附近、相近深度的有效样本估计色度上限与扬尘混色。强降色度仅改 RGB；保留亮度层次、源材质类别、几何透明度和孔洞。扬尘从局部暗部抬升与对比度估计，属于单张照片成像估计，不是实测粉尘浓度。`atmosphere=off` 可诊断关闭。
- 延续有限接收面边界渐隐、只过滤插入颜色差的相机模糊及噪声差额。环境样本不足不扩大到全图。
- 每张结果、命令行进度、网页和批次报告增加累计费用；账本按实际请求记录，包括失败、格式重试和准备调用。缓存命中计零新增调用。续跑累计旧账本，费用缺失或服务未定价不记成免费。自定义价格支持缓存输入单价和币种。
- 过滤器准备时遇到不支持的材质类别，收紧通用视觉分析的枚举提示后完成准备；该失败的两次请求也计费。

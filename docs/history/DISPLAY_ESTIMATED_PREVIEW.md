## 尺度和接触依据

`scale_evidence_policy=estimate_preview` 仅用于 `evidence_v1`、`geometry_preset=rebuild` 与 `uncertain_policy=render_review`。可见车宽对应不足时，以 2.45 米内宽和画面货堆水平跨度建立宽区间先验。程序检查模型提出的参照端点、可见承托面、保护区及相对深度。同层类别参照在估计中的权重为 35%。车型或宽度对应存在明确冲突时停止。该先验只约束估计范围，单张画面仍不足以测量现场透视和钢料高度。

03 使用已核实的 206 mm。22 和 31 分别采用类别区间的几何中点 282.8 mm 和 636.4 mm，在两个场景使用同一实物长度基准。程序按落点和姿态计算投影。合成中可见长边以遮挡后的轮廓测量。

| 物品 | 36_6_24 可见长边 | 53_7_35 可见长边 |
| --- | ---: | ---: |
| 03 轴承座 | 243 px | 256 px |
| 22 气缸 | 405 px | 297 px |
| 31 液压缸 | 753 px | 893 px |

六张均为 `review`。虚拟接收片上的最大接触投影间隙约 1.47 px，接触簇覆盖率最低约 93.7%。现场接触高度仍待核实。36 号场景气缸有一处候选因视觉悬空发现被淘汰，程序自动换位。六张输出均为 3840×2160，读回散列和编辑边界一致，程序记录保护区与前景变动均为 0，物体孔洞 alpha 检查通过，44 个源模型散列一致。

摄影指标达标 2/6，视觉全项通过 0/6。36 号背景的液压缸表面偏平滑、阴影弱，接地观感不足。53 号背景的轴承座仍偏蓝，气缸表面偏净。五张沿用第二阶段优化运行的有效复核，36 号场景轴承座完成了增加直接接触证据字段后的单项复验。

## 模型协议与运行

程序为视觉发现和动作绑定当前图像、物品及证据 ID。执行模型只收到有证据支持的可用操作和绝对值。明确几何缺陷需记录可见的间隙、交叠、穿插或端面支撑线索，阴影与边缘问题可独立记录。格式错误至多重试一次，期间保留有效的已审版本。默认批处理的车宽预检继续使用原规则。

```powershell
$previewPython = 'work/triposr-env/Scripts/python.exe'
$previewScript = 'tools/ps-model-controller/validate_estimated_preview.py'
& $previewPython -X utf8 -B $previewScript freeze
& $previewPython -X utf8 -B $previewScript run
& $previewPython -X utf8 -B $previewScript report
```

`freeze` 保存两张背景及模型散列。修改样本时用 `--out` 指定新目录，可用 `--assets` 和 `--scenes` 选定三个模型 ID 与两个背景编号。用 `run --attempt <名称> --retry-failed` 在独立目录复验未出图项。`report` 复验现有 PNG 并更新全画面页与总览，无新增模型请求。

本轮包含开发期间的格式重试与复验，合计 67 次实际 API 请求，其中 16 次重试，169,645 token。按项目计价配置估算 ¥0.2131–0.4263，本机费用未知。累计批次运行 519.3 秒，Blender worker 108.1 秒，物体、有影、无影各实际渲染 13 次、缓存命中 17 次。首轮 JSON 绑定失败的消耗已计入。

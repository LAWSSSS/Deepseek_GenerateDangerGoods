## 已实现的处理

- `native` 模式默认 `atmosphere: auto`，网页与 JSON 配置一致，`off` 可诊断。同一背景的视觉成像分析与数值场分别缓存；格式失败经过一次修复重试后缓存低置信度结果，全局服务故障仍暂停。
- 多尺度暗通道结合局部样本、排除区域与相对深度，估计空间雾幕颜色和透射率。文字、饱和区、白色平面不降低邻近暗通道。深度关联不足使用同层估计，另记 `depth_confidence: unknown`。
- 原 PBR 材质下新增独立的非金属积灰层。空气参数不改变金属度、粗糙度或积灰颜色；具体“表面过净”动作可增加独立积灰覆盖率。源贴图、源模型和网格未改写。
- 从同深度、中性色可比较表面估计局部照明，不逐件把物体中位数拉到地面亮度。光源方向使用完整相机坐标；宽光源与环境反射共同调整。反射照片只作有限雾幕补偿，不当作已知 HDR。
- 线性 EXR 曝光/白平衡、一次 AgX、解码 sRGB 相机线性近似、空间空气遮蔽、阴影与前景、边缘成像和噪声按顺序合成。阴影只衰减透过雾幕的表面光，不压黑空气光。颜色用 EXR 浮点 alpha 还原，几何 alpha 保持原版本；小孔限制模糊时逐级减弱 PSF。
- 自动动作区分雾感过清/过重、受光方向不符、反射过平/过硬和表面过净。纯雾量修改复用物体及阴影缓存。默认最多两轮修正，继续保留重复参数、无有效动作和无像素变化的停止条件。
- 固定六项和门控 18 项入口、冻结清单、版本签名、同摆位对照与独立诊断目录已接入，见 [使用说明](DISPLAY_BATCH.md#局部受光与薄雾)。

## 未解决项与后续方向

当前程序能复现结果，但还不能稳定输出无插入痕迹的图片。空气遮蔽解决了固定混色问题，无法恢复单张背景没有提供的真实反射环境、局部光源遮蔽和三维接触关系。后续应分别验证源 PBR 响应、照明环境和有限承托面的投影，再改统一策略；不应继续用增加雾量或积灰替代反射与接触证据，也不应降低本轮视觉门槛扩批。

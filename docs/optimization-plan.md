# 废钢异物合成下一步优化方案

基线为公开仓库提交 `a3d643e`。当前版本已能固定批次输入和模型版本、断点续跑、记录几何与摄影检查，并按配置导出 Photoshop 文件。本轮已调整放置、批量生成和建模三个工作台。下面三项是后续开发建议。

## P0　让中断的批次留下可信的终态

批量执行函数一开始就把本轮状态设为 `complete`。已知的渲染、输入或模型服务问题有专门处理，但任务执行期间出现其他异常时，收尾代码仍可能写出“完成”。网页能查看当前子进程的退出状态，服务重启后这条线索就会丢失。维护入口见 [批量执行](../src/scrap_composite/generation/pipeline.py)和[批次状态接口](../src/scrap_composite/frontend/batches.py)。

**建议改动。** 先记录运行中，再根据任务账本写入终态。在摘要中保存运行编号、最后阶段、失败原因及剩余任务数。所有任务都有终态时才报告处理结束，单项失败仍计入失败数。临时故障保留已完成任务和已产生的费用记录。

**验收。** 用离线夹具分别模拟正常结束、单项失败、未分类异常和服务重启。核对网页、摘要和任务账本。续跑后，先前成功的任务应保留相同的产物散列，且不会再次计为新完成或触发重复请求。

## P1　先固定一组样本，再判断合成质量有没有提高

现有评估清单按文件名识别 36、53 两个机位，并固定使用六个物品编号。交接记录里，36 号机位已有阀门复验仍超过 2 px 接触间隙的案例，适合留作回归样本。维护入口见[评估清单](../src/scrap_composite/generation/cli.py)、[接触间隙测量](../src/scrap_composite/generation/strict_contact.py)和[既有复验记录](../DEEPSEEK_HANDOFF.md)。

**建议改动。** 把背景、机位、来源组、物品版本和随机种子写入清单，锁定开发组与留出组。先在开发组查尺度与承托，再比较材质、光色和相机模糊。每次只改变一类因素，同一位置保留基线和新版全图、物体局部及相应检查数据。接触不明确的样本保留“待审”及原因。

**验收。** 同一来源组不能跨集合。每个计划样本都能查到出图、待审、失败或未执行的去向。有图率和展示合格率给出各自的分子、分母；尺度、接触间隙、遮挡和摄影复核分别记录。先在原素材环境复现历史问题，模型外观确认后，再用独立新批次检查留出场景。

## P2　按最终选中的合成图导出训练标注

如果后续要训练检测或实例分割模型，可以复用合成时已经算出的可见区域。生成器已从物品覆盖层中扣除前景遮挡和保护区，并记录可见面积及散列。批次可能从多轮修正中选择最佳图，因此标注必须绑定最后选中的那一轮。维护入口见[可见区域计算](../src/scrap_composite/generation/compose.py)、[分层文件写出](../src/scrap_composite/layers.py)和[选图归档](../src/scrap_composite/generation/pipeline.py)。

**建议改动。** 增加可选的 COCO 实例导出。将可见区域按当前面积统计口径（二值阈值大于 0.5）还原到原图坐标，再由全幅掩膜计算 RLE、边框和面积。记录类别映射版本、模型版本、背景来源、迭代编号、最终图像散列与审核状态。先明确哪些待审结果可进入训练集。

**验收。** 用有孔、部分遮挡、越出画面和带投影阴影的样例回读导出文件。解码后的掩膜必须与选中迭代的二值可见区域逐像素一致，孔洞、遮挡物和阴影不计作物品。标注应能回溯到原背景和模型版本，重新计算的边框、面积与导出值完全一致。
